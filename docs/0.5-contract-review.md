# 0.5 contract and hardening review

Reviewed 2026-10-09 against develop `d9dc322` and published 0.4.0.
Related to API #37 and hardening #38. Version/range changes and the coordinated
candidate-set/website snapshot qualification remain release gates.

## Complete published inventory

| Path / name             | Decision | Reason / migration                                                                                        |
| ----------------------- | -------- | --------------------------------------------------------------------------------------------------------- |
| `.`                     | KEEP     | One service/semantic-locale entrypoint; CLI full-stack templates and API/SSR examples use the factory.    |
| `createI18n`            | KEEP     | Application-authored aligned catalogs and lexical service ownership.                                      |

Published names shrink from nineteen to seven. Seven inference helpers had
leaked through ambient declarations despite lacking source export keywords.
The root is now an explicit barrel over implementation ownership. Every removed
name fails a packed negative type import; the runtime helpers and three retained
types still resolve with catalog-derived key/argument checks.

Workspace searches covered fetched sibling source, templates, examples, docs and
website sources. Production consumers already use the factory and infer their
service types; own type tests were migrated. Generated website API data still
tracks installed 0.4 packages and must be regenerated against the complete
candidate set before API #37 closes.

## Executed hardening matrix

Existing assertions were inspected before adding cases: missing/partial catalogs,
argument-bearing messages, plural categories, copied/frozen catalogs, direction
fallback/overrides, scope isolation and SSR snapshot roundtrips were covered.
The browser suite previously exercised attribute helpers rather than an actual
SSR hydration roundtrip; that integration is now asserted directly.

| Probe                                  | Outcome / evidence                                                                                                                                                                                                                                                                                                                              |
| -------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Malformed maps/source catalogs         | Corrected generic failures for null/non-object maps and null source catalogs; arrays/non-object source catalogs reject with locale-specific diagnostics.                                                                                                                                                                                        |
| Inherited missing message keys         | `toString`, `constructor`, `hasOwnProperty` formerly resolved inherited functions or produced unrelated failures. Both explicit/scoped formatting now require own authored keys.                                                                                                                                                                |
| Non-string results                     | Numbers/null/undefined/objects formerly escaped the string contract. Shared formatting validates both paths with the same locale/key diagnostic. Empty strings and explicitly authored `toString` messages remain valid.                                                                                                                        |
| BCP-47 extensions and overrides        | Numeric/calendar/private-use extensions in Arabic, Hebrew, Latin, Arabic-script Azerbaijani and Gurmukhi resolve correctly; explicit opposite direction wins. Locale keys are preserved, not normalized or implicitly aliased.                                                                                                                  |
| Repeated lexical scopes                | Twenty alternating SSR scopes produce their own locale; reads outside each completed render fail instead of retaining state. Passed.                                                                                                                                                                                                            |
| Real SSR/client hydration and teardown | A browser-generated SSR snapshot hydrates through Askr with markup verification; original boundary element is adopted, Arabic lang/dir/text match, nested English explicit RTL override stays scoped. Six locale switch/hide/show cycles clear and restore attributes, and final root cleanup removes the boundary without page errors. Passed. |
| Installed artifact                     | Normal tarball with minimum Askr 0.4.0 verifies runtime helpers, SSR snapshot, missing inherited keys, metadata/private path rejection, all retained types and twelve negative imports. Passed.                                                                                                                                                 |

The corrected regressions ran against unchanged source with thirteen failures;
46 unit cases now pass, alongside six browser cases. `npm run check` on Node 24
LTS passes lint/types, unit/browser tests, build, real packed consumer, publint
and artifact checks. CI runs the packed contract on all three operating systems.
Coverage evidence is the explicit failed/passing assertions above; no percentage
is claimed. Direct document writes have application-owned cleanup, while lexical
scope/rendered DOM cleanup is qualified by the lifecycle test.
